# Power BI Data Analytics Dashboard

## Project Overview

This project presents an interactive Power BI dashboard created to analyze survey data and generate meaningful insights about respondents, salaries, programming languages, job satisfaction, and work-life balance.

## Dashboard Highlights

- Total number of survey participants
- Average age of respondents
- Average salary by job title
- Favorite programming languages
- Salary distribution by programming language
- Difficulty in breaking into the data field
- Job satisfaction analysis
- Work-life balance analysis

## Tools & Technologies

- Power BI
- Data Visualization
- Data Analysis
- DAX

## Key Insights

The dashboard provides an interactive view of survey responses and helps identify patterns in salaries, programming preferences, job satisfaction, and career-related challenges.
